# AI Vision-Based Autonomous Robot

An autonomous rover using computer vision and ultrasonic obstacle avoidance.

## Hardware
- AI-Thinker ESP32-CAM
- Arduino Nano (USB-to-serial adapter)
- L298N motor driver
- HC-SR04 ultrasonic sensor
- SG90 servo motor
- Four DC gear motors

## Software
- Arduino IDE
- Python
- YOLOv8 object detection
- OpenCV

## Project Structure
- firmware/: ESP32-CAM firmware
- ai-detection/: Python AI vision program
- 3d-model/: 3D design files
- docs/: Wiring and assembly documentation

## Safety
Check wiring, voltage levels, and motor current ratings before powering the robot.
